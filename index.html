HTML

A Estrutura

O HTML (HyperText Markup Language) é o esqueleto do site. Ele define o conteúdo e a organização dos elementos na página, como títulos, parágrafos, imagens, botões e formulários.

CSS

O Estilo

O CSS (Cascading Style Sheets) é a camada visual. Ele controla o design do site: cores, fontes, espaçamentos, layout e responsividade para celular e computador.

JS

JavaScript

A Interatividade

O JavaScript é o cérebro da aplicação. Ele adiciona comportamento dinâmico e lógica, como animações, validação de dados, menus interativos e comunicação com servidores.

Como eles trabalham juntos?

Imagine a criação de um site ou web app como a construção de um carro:

  • HTML: O chassi, as portas e a estrutura metálica do carro.
  • CSS: A pintura, o estofamento dos bancos e o design da lataria.
  • JavaScript: O motor, o sistema elétrico e os comandos do painel.

O navegador lê esses três arquivos em conjunto para transformar linhas de código em uma experiência funcional, rápida e agradável para o usuário.

Roda de Newton Automatizada

Unindo óptica física, mecânica e programação com Arduino e Motor DC.

O Conceito Físico

A Roda de Newton demonstra a síntese aditiva das cores. Um disco dividido nos sete componentes do espectro visível (Vermelho, Laranja, Amarelo, Verde, Azul, Anil e Violeta) é girado em alta velocidade.

Devido à persistência retiniana do olho humano (que retém imagens por cerca de 1/16 de segundo), o cérebro sobrepõe as cores refletidas rapidamente, resultando na percepção da cor branca (ou cinza claro).

A Automação com Robótica

Em vez do acionamento manual tradicional, utilizamos a plataforma Arduino e um Motor DC para controle preciso de rotação (RPM).

  • Arduino Uno: Controla os sinais digitais e a velocidade.
  • Motor DC (5V/12V): Executa a rotação do disco óptico.
  • Driver Ponte H (L298N / Transistor BD139): Fornece a corrente necessária ao motor.
  • Potenciômetro: Permite ao usuário ajustar a velocidade de rotação manualmente.

Como Funciona o Experimento

1

Sinal PWM

O Arduino gera um sinal PWM (Pulse Width Modulation) para controlar a tensão entregue ao motor.

2

Aceleração

Ao girar o potenciômetro, o motor aumenta os RPMs até atingir o limite de frequência crítica da visão.

3

Fusão Óptica

A partir de uma velocidade específica, as cores individuais "desaparecem" e a superfície aparenta ficar branca.

Como Funciona o HTML e o CSS?

Entenda o papel da linguagem de marcação e da linguagem de estilo na construção da Web.

<HTML>

HTML: Estrutura e Marcadores

O HTML (HyperText Markup Language) não é uma linguagem de programação, mas sim de marcação. Ele utiliza tags para indicar ao navegador o que cada parte do texto representa.

  • Tags principais: <h1> para títulos, <p> para parágrafos, <a> para links.
  • Hierarquia: Organiza os elementos em árvore (DOM), definindo quem é elemento pai e quem é elemento filho.
  • Semântica: Ajuda motores de busca (como o Google) a entender o significado do conteúdo na página.
{ CSS }

CSS: Regras e Estilização

O CSS (Cascading Style Sheets) aplica regras visuais aos elementos criados pelo HTML. Ele funciona identificando o elemento (seletor) e declarando propriedades de estilo.

  • Seletores: Apontam para as tags HTML por nome, classe (.classe) ou ID (#id).
  • Cascata e Especificidade: As regras são aplicadas de cima para baixo; seletores mais específicos têm prioridade.
  • Layouts Modernos: Utiliza recursos como Flexbox e CSS Grid para posicionamento e responsividade.

Na Prática: Como se Conectam

O HTML cria o elemento e o CSS altera sua aparência através da ligação no arquivo:

Código HTML 
<button class="meu-botao">
  Clique Aqui
</button>
Código CSS 
.meu-botao {
  background-color: #0070f3;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}
